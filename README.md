# Eye Detective

Prueba de comprensión interactiva del libro *Eyes* (Oxford Read and Discover, Level 1), pensada para niños a los que no les gusta leer.

- 6 misiones + proyecto final "My Eyes" (27 estrellas).
- Las pistas indican la página del libro donde está la respuesta.
- Sin audio: todo es lectura.
- Un solo archivo estático (`index.html`), sin build ni dependencias. Funciona en iPad/Safari.

## Probar en local
Abrir `index.html` en el navegador.

## Deploy
Sitio estático en Vercel (Framework preset: **Other**, sin build command, output = raíz).
